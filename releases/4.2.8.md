# AeroFTP 4.2.8

This documentation accompanies AeroFTP 4.2.8, published on 24 November 2026. The [application changelog](https://github.com/axpdev-lab/aeroftp/blob/v4.2.8/CHANGELOG.md) is the complete release record. Packages are on the [GitHub release](https://github.com/axpdev-lab/aeroftp/releases/tag/v4.2.8). The previous notes stay at [4.2.7](/releases/4.2.7).

The figures below come from [`docs/PROVIDER-INVENTORY.json`](https://github.com/axpdev-lab/aeroftp/blob/v4.2.8/docs/PROVIDER-INVENTORY.json) at the `v4.2.8` tag. They are different counts, not a sum.

## Launch links, presets and file versions

AeroFTP 4.2.8 opens a saved profile or a remote link straight into a connected tab. `sftp`, `scp`, `ftp`, `ftps`, `webdav` and `s3` links, and `--profile`, open one tab and reuse a tab already on that profile. The shared URL table is documented in [Launch arguments](/cli/launch-arguments).

Three presets are new at this tag:

- **Puter** on WebDAV. See the [Puter setup guide](/providers/puter).
- **LifetimeCloud** on WebDAV. See the [LifetimeCloud setup guide](/providers/lifetimecloud).
- **Neon Object Storage** on S3, with per-branch endpoints. See the [Neon setup guide](/providers/neon).

**Blomp** was already a preset. This release lists it on the Add Services Cloud Storage card so the catalog matches. See the [Blomp setup guide](/providers/blomp).

File version history on Nextcloud and MEGA lists the current file first, then older versions newest first. Find Duplicates can refresh a result without a full rescan.

Profiles can also be created from an INI template: the CLI previews with `aeroftp-cli import template` and writes to the vault only with `--apply`.

## How many backends

AeroFTP 4.2.8 reaches **75 connection methods** across **61 providers**. One company on two protocols counts twice. Add Services shows **84 tiles**, because that screen also includes the blank forms and the AeroShare tile.

Under that total the catalog stays split:

| Count | What it is |
| --- | --- |
| 8 | Transport protocols: FTP, FTPS, SFTP, SCP, WebDAV, S3, Azure Blob, OpenStack Swift |
| 26 | Native integrations, each with its own code path |
| 52 | Presets, forms that arrive already filled in |
| 61 | Providers, the companies in the logo grid |
| 75 | Connection methods, the total above |
| 84 | Tiles in Add Services |

The [protocol overview](/protocols/overview) carries this table.

## Sessions stay on the server they started on

A sync, a transfer and a panel action stay bound to the server, profile, account and encrypted folder they started on. A tab switch, a reconnect or a vault change cannot retarget a run. FTP and FTPS encrypted folders refuse a backslash parent step even when the server reports a slash-absolute path. SFTP still treats a backslash as a name character.

macOS 15 and later can reach the local network again. SFTP server compatibility is wider than in 4.2.7.
