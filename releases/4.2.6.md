# AeroFTP 4.2.6

This documentation accompanies AeroFTP 4.2.6, published on 5 November 2026. The [application changelog](https://github.com/axpdev-lab/aeroftp/blob/v4.2.6/CHANGELOG.md) is the complete release record. Packages are on the [GitHub release](https://github.com/axpdev-lab/aeroftp/releases/tag/v4.2.6). The previous notes stay at [4.2.5](/releases/4.2.5).

The figures below come from [`docs/PROVIDER-INVENTORY.json`](https://github.com/axpdev-lab/aeroftp/blob/v4.2.6/docs/PROVIDER-INVENTORY.json) at the `v4.2.6` tag. They are different counts, not a sum.

## SCP

[SCP](/protocols/scp) is an eighth transport protocol. Use it for an SSH server that has no SFTP subsystem, including a stock OpenWrt router. An SFTP profile falls back to SCP on the same connection when the server refuses the subsystem. Choose SCP itself in Add Services or with `scp://user@host/path`.

[AeroCloud setup](/features/aerocloud) does not offer SCP yet. The [mount list](/features/mount-manager) does not include it either. [WinSCP import](/features/winscp) now keeps an SCP session on SCP.

## How many backends

AeroFTP 4.2.6 reaches **70 connection methods** across **56 providers**. One company on two protocols counts twice. Add Services shows **78 tiles**, because that screen also includes the blank forms and the AeroShare tile.

Under that total the catalog stays split:

| Count | What it is |
| --- | --- |
| 8 | Transport protocols: FTP, FTPS, SFTP, SCP, WebDAV, S3, Azure Blob, OpenStack Swift |
| 26 | Native integrations, each with its own code path |
| 47 | Presets, forms that arrive already filled in |
| 56 | Providers, the companies in the logo grid |
| 70 | Connection methods, the total above |
| 78 | Tiles in Add Services |

The [protocol overview](/protocols/overview) is the page that carries this table from now on. Each transport page opens with a short introduction: what the protocol is, when it was first published, who designed it, and how a transfer works.

## Sync, import, and names

[AeroSync](/features/aerosync) can keep a newer destination file and still delete files that exist only on the destination. In the GUI that is Mirror with **Skip newer destination files (One-way Update)**. On the CLI it is `sync --direction upload --update --delete` (or `download`). AeroCloud uses the same idea under Send Only and Receive Only, and it deletes only a destination file this device has already transferred.

Profile import can skip, overwrite, or duplicate a profile that is already saved. The CLI flag is `--on-existing skip|overwrite|duplicate`. The default is still skip. The GUI offers the same three choices.

FileLu's native API can list, download, restore, and permanently delete an earlier version. The version id stays bound to the file you selected. See [FileLu](/providers/filelu).

Proton Drive keeps leading and trailing spaces in a name. A rejected upload no longer drops the valid siblings in the same batch.
